## 4. 기능 목록
🥚**퀴즈 풀기**: 저장된 퀴즈를 순서대로 풀고 정답 여부 및 최종 점수를 확인합니다.  
🥚**퀴즈 추가**: 사용자로부터 새로운 문제, 선택지(4개), 정답을 입력받아 추가합니다. (입력 예외 처리 적용)  
🥚**퀴즈 목록**: 현재 등록되어 있는 모든 퀴즈의 목록을 확인합니다.  
🥚**점수 확인**: 게임을 진행하며 달성한 역대 최고 점수를 확인합니다.
